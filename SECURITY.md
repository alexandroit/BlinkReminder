# Security

Please do not post private settings, machine identifiers or exploitable details in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If it is unavailable, open a public issue asking for a private reporting channel without including the vulnerability details.

The initial 0.1.x line is under active development. Production deployment requires the acceptance and signing checks documented in the release guide. The app must remain a normal-user process; its IPC accepts only a small, explicit command set for the same user and session.
